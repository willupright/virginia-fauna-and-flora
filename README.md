# Virginia Flora & Fauna Database (VFFD)

## Project Overview
Virginia Flora & Fauna Database (VFFD) is a web-based database application designed to store, manage, and explore information about plant and animal species native to Virginia. The system centralizes species data and user-submitted observations to support research, education, and public engagement with biodiversity.

Users can search and filter species by habitat, conservation status, region, and category, while researchers can submit verified observations for review.

---

## Tech Stack
- **Backend:** Python, Flask App Builder
- **Database:** PostgreSQL
- **Frontend:** HTML, CSS (Flask templates)
- **Tools:** SQL, Git

---

## Key Features
- Search and filter species by name, habitat, conservation status, and region
- Centralized database for flora and fauna species
- Researcher observation submission system with admin approval workflow
- Structured relational database design for species, observations, users, and counties
- Role-based access (Admin, Researcher, General Public)
